# Evidence Policy

Claims in this portfolio should be supported by observable project evidence.

Evidence may come from:

- Source code
- Repository structure
- Tests
- Documentation
- Architecture Decision Records
- Deployment artifacts
- Workflow definitions
- Version-controlled infrastructure
- Operational runbooks
- Validation records
- Screenshots
- Demonstrations

The portfolio distinguishes between:

- Verified implementation
- Documented design
- Work in progress
- Planned capability

Planned functionality must not be represented as implemented functionality.

Third-party repositories, forks, clones, libraries, and tools must never be represented as original RACBCONSULTING work.
