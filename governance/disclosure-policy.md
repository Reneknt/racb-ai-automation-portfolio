# Disclosure Policy

This portfolio documents selected technical systems developed by Rene Canete and RACBCONSULTING.

The original implementation repositories may remain private because they can contain proprietary code, operational configuration, internal documentation, infrastructure details, and other non-public material.

Public evidence may include:

- Sanitized architecture diagrams
- Selected screenshots
- Technical descriptions
- Verified technology stacks
- Data-flow diagrams
- Test and validation evidence
- Operational design principles
- Selected non-sensitive excerpts

This portfolio does not publish:

- Credentials
- API keys
- Tokens
- Customer data
- Private contact information
- Sensitive infrastructure topology
- Internal IP addresses
- Security-sensitive configuration
- Proprietary implementation details that would create unnecessary operational or intellectual-property exposure

Private repositories may be available for guided review upon request.
