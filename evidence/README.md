# Evidence Library

This catalog contains selected, sanitized technical artifacts supporting the [project case studies](../projects/README.md). The **case study is the authoritative explanation** of what an artifact demonstrates and, equally importantly, what it does not establish.

| [OperatorOS](racb-operatoros/README.md) | VS Code integration, cockpit, investigation and simulation evidence |
| [Homelab](homelab/README.md) | Container infrastructure, tunnel, host observability and remote development |
| [Production VPS](vps/README.md) | Workloads, health, recovery and SSH hardening checkpoints |

| [Turno](turno/README.md) | Product, access and scheduling-control screenshots and demo video |
| [RACB Voice Platform](racb-voice-platform/README.md) | Evidence boundary; no public runtime media in this folder |
| [RACB Content Platform](racb-content-platform/README.md) | Evidence boundary; no public runtime media in this folder |

Screenshots and demonstrations are **point-in-time evidence**, not guarantees of present uptime, live production operation, or independently reproduced test results. Empty media folders do not imply that the implementation is absent; they indicate that no suitable public media artifact has been published here.

For publication limits and claim standards, consult [Evidence Policy](../governance/evidence-policy.md) and [Disclosure Policy](../governance/disclosure-policy.md).
